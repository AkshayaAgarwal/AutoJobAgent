## 🔄 **Workflow Summary**

### **One-Time Setup (Do This First)**

1. **Gmail API** (15 min)
   - Read: `OLLAMA_GMAIL_SETUP.md` → Step 1
   - Download credentials from Google Cloud
   - Save as `gmail_credentials.json`

2. **Verify Ollama** (5 min)
   - Run: `ollama serve` (keep running)
   - Check: `ollama list` (should show gwen2.7)

3. **Install Dependencies** (5 min)
   - Run: `pip install requests openpyxl google-auth-oauthlib google-auth-httplib2 google-api-python-client`

### **Per-Batch Process (Every Time You Apply)**

1. **Prepare Data** (5 min)
   - Have `jobs_cleaned.xlsx` ready
   - Have your resume file ready

2. **Run Automation** (varies by job count)
   - Run: `python complete_automation.py`
   - Follow prompts
   - Watch emails get generated and sent

3. **Monitor & Track** (5 min daily)
   - Check Gmail for responses
   - Update `recruiter_emails_tracking.xlsx`
   - Follow up after 5 days

## 🎯 **File Purposes Explained**

### **`complete_automation.py` - THE MAIN SCRIPT**

**What it does:**
- Runs all steps automatically
- Generates AND sends emails
- No manual intervention needed

**When to use:**
- When you want everything done in one go
- First-time users
- Bulk applications (50+ jobs)

**Time:** 10-30 minutes for 50 jobs

---

### **`resume_parser.py` - Extract Your Info**

**What it does:**
- Reads your resume (PDF/DOCX/TXT)
- Extracts:
  - Name, email, phone
  - Technical skills
  - Years of experience
  - Previous companies
  - LinkedIn profile

**When to use:**
- First time before generating emails
- Always integrated into `complete_automation.py`

**Time:** 1-2 seconds

---

### **`ollama_email_generator.py` - AI Email Generation**

**What it does:**
- Reads job data from XLSX
- Reads your resume data
- Uses Ollama (Gwen 2.7) locally to generate
- Creates personalized email for EACH job
- Saves to `ollama_generated_emails/` folder

**When to use:**
- To generate emails with review before sending
- When you want to customize emails first
- Always integrated into `complete_automation.py`

**Time:** 30-60 seconds per email

---

### **`gmail_automation.py` - Send Emails Automatically**

**What it does:**
- Reads email files from folder
- Sends via your Gmail account
- Attaches resume (optional)
- Shows success/failure

**When to use:**
- To send generated emails
- Always integrated into `complete_automation.py`
- Can be run separately to send saved emails

**Time:** 5-10 seconds per email

---

### **`job_data_cleaner.py` - Clean Apify JSON**

**What it does:**
- Reads messy JSON from Apify
- Cleans and extracts data
- Creates clean XLSX file

**When to use:**
- ONE TIME at the beginning
- When you export new jobs from Apify

**Time:** 2-5 seconds

## 🔐 **Security Notes**

- ✅ **Ollama:** Runs locally (no data sent anywhere)
- ✅ **Resume:** Only used locally to match jobs
- ✅ **Jobs:** Only used to generate personalized emails

**All processing happens on YOUR computer!**

## 📞 **Support**

### **If you get stuck:**

1. **Check guides:** See above "I want to..." section
2. **Troubleshooting:** Read `OLLAMA_GMAIL_SETUP.md` → "Troubleshooting" section
3. **Specific errors:** Read the error message carefully (usually tells you what's wrong)

### **Most Common Issues:**

1. **"Can't connect to Ollama"** 
   → Run `ollama serve` in another terminal

2. **"Gmail credentials not found"**
   → Download from Google Cloud, follow `OLLAMA_GMAIL_SETUP.md`

3. **"No emails generated"**
   → Check `jobs_cleaned.xlsx` has data, Ollama is running
